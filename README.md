# Revest Full Stack Assignment

## Backend

Two microservices built using NestJS.

### Product Service
CRUD APIs for products.

### Order Service
CRUD APIs for orders and communicates with Product Service.

Run:

cd backend/product-service
npm install
npm run start

cd backend/order-service
npm install
npm run start


## Frontend

Dynamic signup form built with React and Material UI.

Features:
- Dynamic JSON based fields
- TEXT, LIST, RADIO support
- React Hook Form validation
- Responsive UI
- Local storage persistence

Run:
cd frontend
npm install
npm start

cd frontend
npm install
npm start
